How to send

Run for

then
Used by Mode, Relays and Overrides. Example: D-cooling, 5 min, then Standby = machine does D-cooling for 5 min, then stops and waits.

Mode

Click = send now. + = add to the command line instead.

Manual relays (machine goes to Manual)

Click a relay to switch it on (red) or off. Nothing is sent until you press "Send relays". R1 waits the TM1 delay before it starts.

Overrides

Real = machine uses the real input. Off / On = forced. Forcing DI3, DI5 or ignoring a protection switches off machine safety: you will be asked to confirm.

Setpoints (saved in machine, no timer)

Only boxes you change are sent (they turn yellow). Long changes go as 2 or more commands, one after another.

Data interval

s (30 to 300)

Send as a group (uses the choices above)

Sends the overrides first, then the relays or the mode, one after the other, with one click. Example: DI5 = On, T3 = Off, mode D-cooling, 5 min, then Standby.

Graph: past and planned

Left of the dashed "now" line = real data (temperatures, relays, inputs). Right = predicted from the firmware logic: red = relay on, grey = off, striped = cannot be decided now (temperature inside its band, or sensor-fail cycling).

Add steps with the "+ Line" buttons. For each step choose when the next step starts: "right away" (after the machine confirms) or "after 30 min" etc. Example: Charging → after 30 min → D-cooling → after 1 h → end: Standby.

Graph

Zoom: drag a box on the graph, or drag along the time axis (bottom), the °C axis (left) or the V axis (right). Double-click = zoom out one step. Data row: green = sent live, orange = stored while offline and sent later; each small dot = one message. Other rows: red = ON (a dot if short, a line if it stays ON). Grey = OFF. Grey shaded band = no message received (unit off, or messages missed).
